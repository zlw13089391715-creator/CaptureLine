# CaptureLine 使用与验证说明

## 收纳目录与设置

截图和视频共用 `~/Library/Application Support/CaptureLine/Screenshots`。开启「接管截图和录屏」会备份系统捕获保存设置，将保存目标和目录改为内部目录，并关闭系统浮动缩略图。关闭接管或正常退出应用会恢复备份。应用未在运行时不会收纳新捕获。

如果系统录屏工具栏提前打开，设置变化后应按 Esc 关闭，再按 Command＋Shift＋5 重新打开。录屏结束后等待系统完成保存；应用验证文件稳定及可读取的视频轨道后再挂起。

挂起不是另一份副本：挂绳引用原文件。开启接管后可识别的系统桌面录屏如果仍保存到桌面，会在就绪后被移动到内部目录；这条兼容路径可能让桌面短暂出现文件。要完全避开桌面，应让系统直接保存到内部目录。

## 保留与移除

- 单击视频复制文件，双击或长按用默认播放器打开。
- 右键「在访达中显示」可以定位原文件。
- 拖到文件夹或选择「存储到桌面」可以保留到指定位置。
- 内部收纳目录项目点叉会移到废纸篓；外部文件取下时保留原文件。
- 超过挂绳容量会取下最旧的项目，不会因此删除原文件。需要清理遗留文件时可以打开收纳目录。
- 重启按已保存的文件路径恢复；外部删除、改名或移动的文件可能无法恢复。

## 发布与构建

构建方法见仓库 README.md。当前版本支持 macOS 14 及以上，通用二进制包含 arm64 和 x86_64。没有录屏采集功能、内嵌播放器或第三方依赖。

本地应用未经过 Apple 公证。发布修改版需保留 LICENSE 和来源说明，使用独立名称及图标；具体来源见 CREDITS.md。

媒体集成检查覆盖：正在写入的文件、视频轨道可读性、损坏文件、处理中删除、重复发现、桌面系统录屏命名、文件移动及冲突、复制、恢复和保存设置备份还原。测试视频是合成素材，测试配置与真实用户保存设置隔离。

实际系统录屏已确认正常挂起，直接保存到内部目录时桌面不出现文件。1.0.4 的跨应用和全屏设置已通过通用构建、签名及打包检查；仍需在实际全屏应用、不同桌面和台前调度中进一步确认。不将构建成功视为所有系统版本上的实测通过。
